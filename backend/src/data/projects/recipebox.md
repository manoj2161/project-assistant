# RecipeBox

## Project Name
RecipeBox

## Project Type
Recipe discovery and recipe browsing web application.

## Purpose
RecipeBox allows users to discover and explore recipes through a web interface.

## Technology Stack
- React
- JavaScript
- CSS
- Axios
- TheMealDB API

## Main Features
- Browse recipes
- Search and discover recipes
- Display recipe information
- Use TheMealDB API to retrieve recipe data
- Client-side user-related functionality

## API
RecipeBox uses the TheMealDB API to retrieve recipe data.

## Frontend
The frontend is built with React.

Axios is used for making API requests.

## User Data
RecipeBox uses browser storage for user-related application data.

The application uses the following storage key:

- `recipeBoxUsers`

## Project Structure
The application is primarily a frontend React project that communicates with TheMealDB for recipe data.

## Important Notes
- The project is called RecipeBox.
- The recipe data source is TheMealDB.
- Do not assume that RecipeBox uses a custom recipe backend unless the project documentation explicitly states it.
- Do not confuse RecipeBox with other recipe applications.
