# Personal Portfolio

## Project Name

Personal Portfolio

## Project Type

Personal developer portfolio website.

## Purpose

The portfolio presents Manoj Kumar's developer profile, technical skills, projects, and professional information.

## Technology Stack

- React
- Tailwind CSS
- React Router

## Main Features

- Developer profile
- Skills section
- Projects section
- Portfolio navigation
- Responsive design
- Project links
- Contact/professional information

## Design

The portfolio uses a brutalist-inspired modern design.

The design is responsive and intended to work across different screen sizes.

## Navigation

React Router is used for client-side routing.

The portfolio also includes scroll-to-top behavior and animations.

## Projects

The portfolio showcases the user's development projects.

Habitly is one of the user's main projects and is treated as a separate project in the Project Assistant.
